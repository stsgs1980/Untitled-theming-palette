# План: отвязка от песочницы и чистка проекта

Дата: 2026-10-21
Предыдущий план: [2026-10-21-webstorm-config-adaptation.md](2026-10-21-webstorm-config-adaptation.md)

Этот план отменяет решение «пакетный менеджер остаётся Bun» из предыдущего плана: после удаления
песочницной оркестрации связка с Bun исчезла, и проект переведён на npm.

## Причина

Проект начинался в песочнице, где деплой и dev-сервер запускались скриптами `.zscripts/`.
Сейчас проект от песочницы не зависит, поэтому её артефакты и шаблонный балласт больше не нужны.

## Решения

| Решение           | Обоснование                                                       |
| ----------------- | ----------------------------------------------------------------- |
| npm вместо Bun    | Нет `.zscripts/`, шаблон и его docs используют `npm run`          |
| Prisma удалён     | Страница статична, схема User/Post никем не задействована         |
| shadcn/ui обрезан | Из 48 файлов достижимы только badge, button, input, sonner        |
| standalone удалён | Нужен был только для песочницного Caddy-деплоя                    |
| Исключения сняты  | После обрезки все файлы проходят лимит 250 строк и правила ESLint |

## Шаги

1. Удалить артефакты песочницы: `.zscripts/`, `Caddyfile`, `download/`, `mini-services/`,
   `examples/`, `tests/*.sh`, `prisma/`, `db/`, `.env`.
2. Удалить мёртвый код: `src/hooks/use-toast.ts`, `src/hooks/use-mobile.ts`, `src/lib/db.ts`,
   `src/app/api/route.ts`, `tailwind.config.ts`, `scripts/copy-standalone.ts`.
3. Удалить 44 неиспользуемых компонента `src/components/ui/`.
4. Переписать `package.json`: 11 зависимостей вместо 46, без Prisma, скрипты `build`/`start`
   без standalone.
5. Перейти на npm: удалить `bun.lock`, выполнить `npm install`, получить `package-lock.json`.
6. Перевести хуки Husky на `npx`/`npm run`, CI — на `setup-node` + `npm ci`.
7. Привести 4 оставшихся компонента shadcn к правилам шаблона (JSDoc, тип возврата).
8. Обновить README, AI Rules, план предыдущей адаптации и worklog.
